# Hack Nerd Font

Source: https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/Hack

Regular, Bold, Italic, and BoldItalic are the complete Hack Nerd Font faces (including Nerd Font glyphs), converted losslessly from upstream TTF to WOFF2 with FontTools. No subsetting or renaming. `sources.json` records original download URLs and SHA-256 hashes. See `LICENSE.md` for the upstream Hack / DejaVu / Bitstream notices. These files are served locally; no system-font installation or font CDN is needed.
